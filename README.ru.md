# Информационные и технические средства защиты авторских прав

[English](README.md) · **Русский**

Лабораторные работы по курсу БГУИР о защите информации и авторских прав: от классических
шифров до криптосистем с открытым ключом, цифровой подписи, стеганографии и
физически неклонируемых функций.

**Автор курса:** профессор Ярмолик Вячеслав Николаевич, д-р техн. наук —
[персональная страница на сайте БГУИР](https://www.bsuir.by/ru/kaf-poit/yarmolik-v-n)

## ЛР №1: шифры перестановок и подстановок

- **Перестановки:** железнодорожная изгородь, столбцовый метод (одинарный и двойной),
  поворачивающаяся решётка.
- **Подстановки:** Цезарь и аффинный шифр, Плейфейр, Виженер (прямой, прогрессивный и
  самогенерирующийся ключ).

Все восемь эталонных примеров методички воспроизводятся посимвольно.
Отчёт ([PDF](report/main.pdf), [исходник](report/main.tex)), реферат
«Доказательство с нулевым знанием» ([PDF](referat/main.pdf)) и
[теория](labs_info/lab1_theory.md) — на русском.

## Быстрый старт

Python 3.9+, только стандартная библиотека.

```bash
python3 main.py gui     # окно: выбор шифра, параметры, разбор работы
python3 main.py demo    # прогон всех примеров методички с проверкой
```

Окно открывается на английском; язык переключается в селекторе на верхней панели.

```bash
python3 main.py fence    enc -k 4 -t "Это лабораторная работа по КиОКИ"
python3 main.py column   enc -k КРИПТОГРАФИЯ -d ШИФРОВАНИЕ -t "Это лабораторная работа по КиОКИ"
python3 main.py grille   enc -k 0,7,10,13 -t "ШИФРОТЕКСТ"
python3 main.py caesar   enc -k 5 -m 3 -t "Cryptography"
python3 main.py playfair enc -k CRYPTOGRAPHY -t "ciphertext"
python3 main.py vigenere enc -k MODE -s progressive -t "Cryptography"
```

`dec` выполняет обратное преобразование с тем же ключом, `--raw` отключает группы по
5 символов, текст можно подать через stdin.

## Структура

```
main.py       CLI всех лабораторных работ
configs/      ключи и параметры по умолчанию (переопределяются через env)
helpers/      нормализация текста, числовой ключ из слова, выбор алфавита
lab1/         шифры и demo-прогон
gui/          окно на tkinter (methods.py — реестр шифров, i18n.py — переводы)
report/       отчёт по ЛР1 (LaTeX + PDF)
referat/      реферат (LaTeX + PDF)
```

## Сборка PDF

cd report && tectonic main.tex    # или: latexmk -pdf main.tex
